## Table primitives adapted from tablecn

- Source: [sadmann7/tablecn](https://github.com/sadmann7/tablecn)
- Files adapted: `src/registry/bases/radix/ui/table.tsx`
- Local adaptation: `src/components/ui/table.tsx` and the catalog table styles in `src/App.css`
- License: MIT

The upstream tablecn demo is a Next.js application with TanStack Table, URL state, and server-side data features. This project uses the table primitives and interaction patterns that fit its Vite-based static catalog; the catalog's single scroll viewport, column resize handles, search, status filters, and export remain locally implemented.
