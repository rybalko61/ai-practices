# Практики с AI

Небольшая база знаний команды продуктового дизайна: AI-практики, статусы, сравнение времени до и после автоматизации и экспорт в Excel.

## Локальный запуск

```bash
pnpm install
pnpm dev
```

Для production-сборки:

```bash
pnpm build
```

## Публикация на GitHub Pages

В репозитории откройте **Settings → Pages** и выберите **GitHub Actions** в качестве источника публикации. Workflow из `.github/workflows/pages.yml` соберёт приложение и опубликует его при каждом push в `main`.

Исходники сайта находятся в `src/`. Записи пока заданы в приложении как демонстрационные данные.
